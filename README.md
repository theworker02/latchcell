# latchcell

Latch HTML/Markdown cell fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/latchcell/

## Install / run

```bash
git clone https://github.com/theworker02/latchcell.git
cd latchcell
node src/cli.js
node --test
```
